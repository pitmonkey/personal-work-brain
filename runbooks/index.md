# Runbooks

Step-by-step operational procedures. Each is a `Runbook` concept.

A runbook belongs here when it is *yours* — a procedure you worked out and would
otherwise have to re-derive. If the team owns the procedure, it belongs in the
team's system of record; link to it and keep only the gotchas that the official
version omits.
