# Daily

One file per day, `daily/YYYY-MM-DD.md`. Obsidian's core Daily notes plugin creates today's note from [the template](../templates/daily.md) when the vault opens; the settings ship in `.obsidian/daily-notes.json`.

**Notes are not listed here.** Filenames sort by date, and Obsidian's calendar and *previous / next daily note* commands do the navigating. This page is the only index the section needs.

**You write these; the agent tends them.** The agent does not rewrite your prose. It may tick or move todos (depending on your todo mode in [working setup](../me/working-setup.md)), promote a big meeting into [meetings/](../meetings/index.md), and add links.

**Confidentiality applies while you type.** A daily note skips the `inbox/` redaction step — it is written straight into a committed folder. The same never-record rules hold here as everywhere (see [CLAUDE.md](../CLAUDE.md)), and the pre-commit secret scan is the backstop, not the plan.

How the workday flow, todo modes, and meeting promotion fit together: [docs/daily-notes.md](../docs/daily-notes.md).
